# Restaurant Bootstrap Web Page

This is a restaurant website built with Bootstrap. It is a static website with a home page, an about us page, and a contact us page.

## Features

*   Home page with a carousel of featured dishes.
*   About us page with information about the restaurant and its chefs.
*   Contact us page with a contact form and a map.
*   Responsive design that works on all devices.

## Technologies Used

*   HTML
*   CSS
*   Bootstrap
*   JavaScript
*   Node.js
*   npm

## Setup and Usage

1.  Clone the repository.
2.  Run `npm install` to install the dependencies.
3.  Open the `index.html` file in your browser.
